# 🚀 GUI Interactiva - Sistema de Estaciones de Carga Eléctrica

## ✅ Creación Completada

Se ha desarrollado una interfaz gráfica completa en Java Swing con las siguientes características:

### 📦 Archivos Creados

```
src/main/java/com/user/gui/
├── LoginFrame.java        (130 líneas)   - Autenticación de usuario
├── UsuarioPanel.java      (235 líneas)   - Panel para usuario regular
├── AdminPanel.java        (370 líneas)   - Panel para administrador
└── MainWindow.java        (205 líneas)   - Controlador principal

Archivos ejecutables:
├── run.bat               - Script para Windows
├── run.sh                - Script para Linux/Mac
├── GUI_README.md         - Documentación completa
└── GUIA_INICIO.txt       - Este archivo
```

---

## 🎮 Cómo Usar

### **Opción 1: Ejecutar con Script (Recomendado)**

**Windows:**
```bash
cd C:\2026\ElectricChargingStations-CR\ElectricChargingStations-CR
run.bat
```

**Linux/Mac:**
```bash
cd ElectricChargingStations-CR
bash run.sh
```

### **Opción 2: Ejecutar Manualmente**

```bash
cd src/main/java
javac -d ../../../target/classes -cp "." \
  main/ElectricChargingStationsCR.java \
  com/user/gui/*.java \
  com/user/model/*.java \
  com/user/listas/*.java \
  com/user/estructures/*.java \
  com/user/algoritmos/*.java

java -cp ../../../target/classes main.ElectricChargingStationsCR
```

## 📊 Funcionalidades por Tipo de Usuario

### 👥 USUARIO REGULAR

| Pestaña | Descripción | Datos Mostrados |
|---------|------------|-----------------|
| **🏪 Estaciones** | Ver todas las estaciones disponibles | ID, Nombre, Ubicación, Cargadores, Estado |
| **🚗 Mi Vehículos** | Listar sus vehículos registrados | Placa, Marca, Modelo, Capacidad Batería |
| **📅 Mis Reservas** | Historial de reservas personales | ID, Vehículo, Fecha/Hora, Estado |
| **⚡ Mis Cargas** | Historial de cargas realizadas | ID, Vehículo, Estación, Energía, Costo, Fecha |

**Estadísticas disponibles:**
- Total de cargas realizadas
- Energía total consumida (kWh)
- Costo total pagado (₡)

---

### 🛡️ ADMINISTRADOR

| Pestaña | Descripción | Funcionalidades |
|---------|------------|-----------------|
| **🏪 Estaciones** | Gestión de estaciones | Ver, Agregar, Editar, Eliminar |
| **👥 Usuarios** | Gestión de usuarios | Ver, Desactivar usuarios |
| **🚗 Vehículos** | Listado de vehículos | Ver todos, Filtros por propietario |
| **⚡ Cargas** | Monitoreo de cargas | Ver todas, Estadísticas totales |
| **📅 Reservas** | Gestión de reservas | Ver, Confirmar, Cancelar |
| **💰 Reportes** | Panel de estadísticas | Resumen completo del sistema, Exportar datos |

**Reportes disponibles:**
- Total de estaciones, usuarios, vehículos
- Energía total consumida del sistema
- Ingresos totales generados
- Cantidad de cargas y reservas
- Exportación de reportes

## 🐛 Solución de Problemas

### **Problema: "No se encuentra Java"**
- **Solución**: Instale Java 8 o superior desde java.com

### **Problema: "Ventana no se abre"**
- **Solución**: Verificar que compile sin errores y reintentar

### **Problema: "No muestra datos"**
- **Solución**: Verificar que las listas estén cargadas en memoria

### **Problema: "Login falla"**
- **Solución**: Verifique credenciales (admin/admin123 para admin)
